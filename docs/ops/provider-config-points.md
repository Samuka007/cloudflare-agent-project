## 3. 配置变更语义

- **edge 侧 = 重部署**：正本是 Worker vars/secrets，改 env → 重部署生效。`POST /system/config/reload` 是刻意 no-op（「Worker config source is env vars, so there is nothing to reload」，routes/system.ts）。
- **daemon 侧 = 改 env + 重启 daemon client**。
- **设置面不是第二权威**：control-plane-layer §1.2——provider 配置 UI 不得长出工具/引擎启停的第二裁决点；§3.2——秘密与部署拓扑不落控制面 DB，`app_settings` 不承载 provider 配置。

## 4. 秘密纪律（评审断言基线）

投影端点与 SPA 节的零秘密值断言由 L1 钉死：`apps/server-worker/test/compat/system-provider-projections.test.ts`「never emits secret values」用例注入假 key（relay/brave/searxng）后对序列化响应断言 `not.toContain`。新增 provider 配置点进本表时，必须同步回答两问：投影面是否需要它？需要则只加存在性 boolean，永不透传值。
